# 购物应用设计约定

使用既有 GoCMS 后台的 Base Nova 组件、Geist 字体和中性色系统，保持购物应用自己的业务布局。Hallmark 参考范围是 App screens 的数据状态、表单流程和页面交互；不引入营销页面模板。

- 商品列表、详情及规格选择沿用主题生成的 HTML；React 不提供商品列表页。
- 登录、注册使用独立页面，登录后回到原操作页面。
- 购物车以行呈现规格和数量，摘要按币种显示下一步操作。
- 结算使用联系信息、地址、付款方式和订单摘要，移动端按相同顺序展开。
- 结果页根据服务端状态显示待付款、已付款、退款及交付信息。
- 页面覆盖加载、空、失败重试和完整数据状态；操作错误使用可读 Toast。
- 官方 UI 原样共享，业务封装放在本应用；页面滚动统一使用 ScrollArea。
- 颜色和字体在 CSS 变量中定义，保留键盘焦点和减少动态效果设置。

按用户要求，本次不执行设计扫描、构建、自动化测试和浏览器视觉验收。
