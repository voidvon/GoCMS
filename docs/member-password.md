# Storefront 密码管理与找回

## 后台入口

**平台管理 → 邮件设置**：`/admin/mail`，仅超级管理员的后台会话可读写，站点管理员和 API Key 无权访问。

全部站点共享 SMTP、发件人和公开联系邮箱。配置不受当前站点切换影响。可以只保存联系邮箱，保持邮件找回关闭；联系邮箱会出现在前台找回密码页，点击后通过用户邮件客户端联系管理员，不会自动批准重置。

SMTP 支持 STARTTLS（通常 587）和隐式 TLS（通常 465），要求证书有效且使用 TLS 1.2 以上，不提供明文或跳过证书校验的选项。可填写认证用户名和密码／应用授权码；受信任的 TLS 邮件中继也可不使用 SMTP 认证。发件地址应有邮件服务商的发送权限，按服务商要求配置域名验证及 SPF/DKIM 等。

SMTP 密码加密保存，留空保留现有值，读取接口不返回明文。与第三方登录共用 `data/member-login.key` 服务级主密钥，SMTP 使用独立加密作用域。邮件设置页面支持生成、导入和下载密钥备份；恢复数据库时必须恢复同一密钥，不能重新生成覆盖。支付密钥保持独立。

保存后可向指定邮箱发送测试邮件；总开关关闭时仍可测试，避免为调试提前开放找回。测试只确认邮件服务器接收成功，不保证收件箱投递成功；需检查垃圾邮件及服务商投递日志。

## 前台流程

- 登录页“忘记密码？”进入 `/shop/forgot-password`。
- 邮件开启且当前来源属于已配置站点时，会员输入注册邮箱。对存在与不存在账号返回相同响应，避免泄露账号是否存在。
- 后台配置的公开联系邮箱始终可展示。邮件关闭或不可用时隐藏邮件发送表单，显示通过已绑定第三方账号验证或联系管理员的说明。
- Google / Facebook 按各自平台开关和凭据可用性显示“验证”按钮。完成授权后只接受已绑定、有效且属于当前站点的会员，不依据邮箱匹配、不自动注册、不新增站点归属，也不创建会员登录会话。
- 没有邮箱的 Facebook 会员也可以通过原绑定验证身份，为账号设置本地密码。未绑定的第三方账号不能用于找回；管理员联系邮箱也不构成身份证明。
- 身份验证通过后进入 `/shop/reset-password#token=...`，输入并确认新密码。完成后返回登录。
- 登录后的用户名入口进入 `/shop/account`，在“修改密码”中输入当前密码和两次新密码。无本地密码时提供验证后设置密码的入口。

密码至少 8 字节、最多 1024 字节，沿用现有 Argon2id 哈希机制。账号在全部站点共用同一密码。修改或重置后撤销该会员所有站点、所有设备的会话，当前站点 Cookie 同时清除，需重新登录。其他站点 Cookie 虽仍可能存在，其服务端会话已失效。

## 重置凭证与配置边界

重置令牌由密码学安全随机数生成，只在数据库保存 SHA-256 摘要；有效期 30 分钟、仅能消费一次，同一会员新验证会替换旧凭证。凭证绑定实际站点、会员邮箱、当前密码指纹和验证渠道。改变密码或邮箱、停用会员、移除站点归属、停用站点都会阻止使用旧凭证。

邮件凭证同时绑定邮件配置版本；修改邮件配置或关闭邮件会使其失效。第三方凭证绑定原提供商配置版本和具体身份；关闭或更新该提供商、解除绑定后不能继续使用。第三方找回不依赖邮件总开关。

邮件重置链接的来源来自启用站点的域名、别名、独立语言域名和归属匹配的站点公开地址目录，不接受任意 Host 或 `X-Site-Id` 作为链接来源。本地开发需在站点公开地址中登记包含端口的 localhost 地址。生产使用 HTTPS。

令牌放在 URL fragment，不进入 HTTP 请求及 Referer。客户端以 JSON POST 提交令牌；日志和公开响应不输出令牌、密码、SMTP 错误详情或收件人。未知邮箱与已注册邮箱均由有并发上限的异步任务处理，不等待 SMTP 来区分响应时间。发送失败会撤销该次邮件凭证并记录不含敏感信息的失败事件。发送任务不跨进程重启持久化；若重启导致邮件未发送，会员可重新申请。

找回请求、密码提交、改密及后台测试邮件均有限流。支持邮箱人工联系时，管理员仍需使用自己的身份核验流程，不应仅凭一封自称会员的邮件修改密码。

## 接口

| 接口 | 用途 |
| --- | --- |
| `GET /api/admin/mail` | 全平台邮件配置与加密密钥状态 |
| `PUT /api/admin/mail` | 带 revision 保存配置和可选 password |
| `POST /api/admin/mail/test` | 使用已保存 SMTP 配置向 email 发送测试邮件 |
| `GET /api/v1/auth/password-options` | 当前来源的邮件找回可用状态及公开 support_email |
| `POST /api/v1/auth/forgot-password` | 提交 email、language，统一返回 accepted |
| `POST /api/auth/{google\|facebook}/start` | 传 recover:true 开始已绑定账号的验证；不能同时 bind:true |
| `POST /api/v1/auth/reset-password` | 提交 token、password，消费凭证并撤销会话 |
| `PUT /api/v1/me/password` | 提交 old_password、new_password，验证当前密码后撤销会话 |

`GET /api/v1/me` 新增 `has_password`，供账号安全页区分修改密码和首次设置密码。前台页面与错误信息同步支持全部 11 种语言，重置邮件也按前台语言发送。

自动测试覆盖邮件编码、TLS/STARTTLS 投递、拒绝明文 SMTP、公开联系邮箱、后台权限、凭据加密与作用域、隐藏账号存在性、邮件重置、第三方验证、跨站拒绝、过期、重放、配置／绑定失效、密码修改及会话撤销。真实 SMTP 与第三方授权需配置实际凭据后联调。

安全设计参考：[OWASP Forgot Password Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Forgot_Password_Cheat_Sheet.html)。
