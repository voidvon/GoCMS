# Geographic data attribution

The bundled `data/countryInfo.txt` is an unmodified GeoNames country information
snapshot downloaded on 2026-11-07 from:
https://download.geonames.org/export/dump/countryInfo.txt

GeoNames data: https://www.geonames.org/
License: Creative Commons Attribution 4.0 International (CC BY 4.0)
https://creativecommons.org/licenses/by/4.0/

This module transforms imported GeoNames files into indexed SQLite catalogues.
The data is provided as-is, without guarantees of accuracy or completeness.
See https://download.geonames.org/export/dump/readme.txt for field definitions.
This data license applies to geographic data, not the GoCMS application code.
